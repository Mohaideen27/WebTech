# Looping Statement

## For loop

**_syntax_**

```js
for (initialization; condition; updation) {
  //code block
}
```

**_example_**

```js
for (let index = 0; index < =5; index++) {
    console.log(index);


}
```

## While Loop

```js
//initialization
while (condition) {
  //updation
}
```

**_example_**

```js
let i = 10;
while (i <= 20) {
  console.log(i);
  i++;
}
```

## Do While Loop

```js
//initialization
do {
  //updation
} while (condition);
```

**_example_**

```js
let i = 10;
do {
  console.log(i);
  i++;
} while (i <= 20);
```
