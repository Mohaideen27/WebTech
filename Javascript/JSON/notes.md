# JSON

- JSON [Javascript Object Notation] is a light weight data interchange format
- that is easy for humans to read and write and easy for machine to parse and generate.

## Advantages of JSON

- **_Human readable_**
  - JSON structure is easy for developers to understand and write
- **_LightWeight_**
  - JSON is a minimal format that reduce the size of the data being transmitted.

- **_Language Independent_**
  - JSON can be used with many programming languages like python, java, javascript, etc..
