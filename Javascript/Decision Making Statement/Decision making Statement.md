## If condition

**_syntax_**

```js
if (condtion) {
  //true block
}
```

## If else condition

**_syntax_**

```js
if (condition) {
  //true block
} else {
  //false block
}
```

## If else ladder

- if we want to check more than one condition then we should use this.
- any one block is executed means it will not check the remaining blocks.

**_syntax_**

```js
if(condition 1){
    //code block
}else if(condition 2){
    // code block
}else{
    //false block
}
```
